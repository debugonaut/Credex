================================================================================
                        TECHNICAL DECISIONS
================================================================================

1. Integer Cents
   All financial math in cents (e.g., $20 = 2000), never floats.
   Prevents rounding errors that are embarrassing in financial tools.

2. Deduplication by Highest Savings
   When multiple rules fire on same tool, keep only highest-savings rec.
   Prevents double-counting savings.

3. Noise Floors
   Ignore recommendations < $5/month. Switching friction exceeds benefit.

4. Conservative Credex Discount
   Estimate 15% discount (not 20%+). Overclaiming damages credibility.

5. Overlap Matrix as Constant
   Define tool overlaps explicitly, not inline. Testable & maintainable.

6. Form Persistence with Debounce
   Auto-save to localStorage, debounced 500ms. Better UX.

7. Zod Schema as Single Source
   Define validation once, import everywhere. Type-safe & DRY.
